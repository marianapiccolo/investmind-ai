# Portfolio Performance

Portfolio performance describes how the value of an investment portfolio has
changed over time.

Performance analysis should distinguish investment returns from cash flows
such as deposits and withdrawals.

Different return measures answer different questions and should not be used
interchangeably.

## Time-Weighted Return

Time-weighted return, commonly abbreviated TWR, measures investment
performance while reducing the influence of external cash flows.

The measurement period is divided around deposits and withdrawals, and the
sub-period returns are geometrically linked.

TWR is useful when the goal is to evaluate the performance of the investment
strategy independently of the timing and size of investor cash flows.

It does not directly represent the personal return experienced by an investor
whose deposits and withdrawals occurred at different times.

## Money-Weighted Return

Money-weighted return incorporates the timing and size of cash flows.

It reflects the return experienced by the investor and is closely related to
the internal rate of return concept.

Large contributions made before strong or weak market periods can materially
affect money-weighted performance.

For this reason, money-weighted return can differ substantially from
time-weighted return for the same portfolio.

## XIRR

XIRR is a money-weighted return calculation designed for cash flows occurring
on irregular dates.

It estimates the annualized discount rate that makes the net present value of
the portfolio cash flows equal to zero.

XIRR is useful for investor-level performance because real deposits,
withdrawals, and ending portfolio values rarely occur at perfectly regular
intervals.

The result can be sensitive to the cash-flow pattern and may not always have a
unique economically meaningful solution.

## Performance Attribution

Performance attribution attempts to explain where portfolio gains or losses
came from.

A portfolio-level return can be decomposed into contributions from different
assets, positions, sectors, or other dimensions.

Attribution helps distinguish the overall portfolio result from the
contributions of individual holdings.

A strong contribution from one asset does not necessarily mean the portfolio
is well diversified or that the same contribution will continue in the
future.

## Past Performance

Historical performance describes what occurred during a specific period.

It should not be treated as a guarantee or prediction of future returns.

Performance should be interpreted together with risk, benchmark behavior,
portfolio composition, and the period over which the result was measured.

# Investment Returns

Investment return measures the gain or loss generated by an investment over a
period of time.

Returns may be expressed in absolute monetary terms or as percentages.

The appropriate return measure depends on the analytical question being
asked.

## Simple Return

A simple return compares the change in value with the starting value.

For an asset without external cash flows, the percentage return represents
the gain or loss relative to the initial value.

Simple returns are intuitive for individual periods but cannot always be
added directly across multiple periods.

## Cumulative Return

Cumulative return represents the total percentage change over a multi-period
investment horizon.

It reflects the combined effect of the sequence of periodic returns.

Cumulative return does not by itself describe how volatile the path was or
how long the investment took to produce the result.

## Compounding

Investment returns compound over time.

If an investment gains 10% and then loses 10%, it does not return exactly to
its starting value because the second percentage change is applied to a
different base.

This means sequential percentage returns should normally be geometrically
linked rather than simply added.

## Annualized Return

Annualized return expresses multi-period performance as an equivalent yearly
rate.

It can make returns over different investment horizons easier to compare.

Annualization does not mean the portfolio actually earned the same return in
each individual year.

Annualized metrics can also be misleading when based on very short historical
periods.

## Nominal and Real Return

Nominal return measures the investment result without adjusting for changes in
purchasing power.

Real return considers the effect of inflation.

An investment can therefore generate a positive nominal return while producing
a much smaller real increase in purchasing power.

## Return Interpretation

Return should not be evaluated independently from risk.

Two portfolios can produce similar returns while experiencing very different
volatility, drawdowns, concentration, or liquidity characteristics.

A meaningful analysis therefore considers both return and the risk taken to
achieve it.
